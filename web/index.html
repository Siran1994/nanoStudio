💡 视觉推理原理:

图像进入网络后，经过卷积与池化层逐层提取边缘、纹理与高级语义特征，最终在全连接层输出各类别的未归一化对数概率（Logits），通过 Softmax 函数变换为和为 100% 的概率分布。

🔬 卷积神经网络 (CNN / ResNet) 核心原理拆解

从图像局部感知到深层特征抽象的数学机制
特征提取

2D 卷积层 (Conv2d)

通过可学习的卷积核在图像上滑动做点积，捕捉边缘、角点等空间局部模式，具有平移不变性。

Output(i,j) = Σ Σ Input(i+m, j+n) × Kernel(m,n)
空间下采样

最大池化 (MaxPool2d)

将分辨率缩小一半（如 32x32 -> 16x16），减少计算量并增强模型对微小形变的鲁棒性。

Output = max(Window(2×2))
梯度高速公路

残差跳跃连接 (Residual Shortcut)

ResNet 核心发明：让网络学习恒等映射加残差 F(x) + x，从根本上解决深度增加时的梯度消失与退化问题。

y = F(x, {Wi}) + x
概率归一化

Softmax 分类器

将高维特征线性映射为对应每个类别的得分，并归一化为互斥事件概率。

P(y=k|x) = e^(z_k) / Σ e^(z_j)
